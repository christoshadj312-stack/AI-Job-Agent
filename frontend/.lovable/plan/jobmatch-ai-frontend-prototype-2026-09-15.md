# JobMatch AI frontend prototype

## Scope
Build a polished, responsive, frontend-only SaaS prototype using realistic mock data and simulated interactions. No backend, sign-in, database, APIs, or real AI processing will be added.

## Experience
- Create a shared app shell with branded sidebar navigation and a compact user profile.
- Build distinct pages for Dashboard, New Analysis, Analysis Results, Application Tracker, Cover Letters, History, and Settings.
- Add the CV upload state, job description form, simulated four-step analysis progress, and transition into results.
- Make results the visual centerpiece with match scoring, category progress, requirement evidence, strengths, gaps, recommendations, and an editable/copyable/downloadable cover-letter preview.
- Add tracker search, status filtering, an application detail panel, and mock add-application flow.
- Include purposeful empty, loading, mobile navigation, and interaction states.

## Visual direction
- Light neutral canvas, crisp white surfaces, restrained teal/green and amber/red status accents.
- Professional typography, compact radii, subtle borders/shadows, generous spacing, and restrained motion.
- Use semantic design tokens throughout, with accessible contrast and responsive layouts.

## Validation
- Verify every route has unique metadata.
- Check desktop and mobile layouts and exercise the analysis and tracker interactions in the live preview.
- Confirm the preview builds without errors.
